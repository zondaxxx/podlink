# Podlink — управление AirPods на Android без root

Готовый APK лежит рядом с этим файлом: `Podlink-0.5.0-release.apk` (подписан своим ключом, ставится поверх предыдущих версий).

Исходники: папка `Podlink/` (Kotlin, Jetpack Compose, Material You, minSdk 26, targetSdk 36 / Android 16).

## Что умеет

**База, как у CAPod / AndroPods / MaterialPods:**
- Заряд левого, правого и кейса, зарядка, крышка, наушник в ухе, сторона микрофона, статус «музыка / звонок».
- Пауза при вынимании наушника, продолжение при возврате, режим «один наушник», «включать музыку, когда оба в ушах».
- Попап в стиле iOS при открытии кейса и при подключении: свайп вниз, тап мимо, автозакрытие по таймеру и при закрытии крышки, на экране блокировки.
- Постоянное уведомление, плитка в шторке, виджет двух размеров под Material You.
- Определение модели по BLE-пакету: AirPods 1/2/3/4, Pro/Pro 2/Pro 3, Max/Max 2, Beats.
- Темы: система / тёмная / светлая, цвета Material You.

**Чего нет у остальных без root:**

1. **Проценты заряда в статус-баре.** Иконка уведомления рисуется как число (наименьший наушник, или левый/правый/кейс на выбор) с молнией при зарядке.
2. **Автоподключение** при открытии кейса, при появлении рядом или при вставлении в ухо. Скрытый `connect()` профиля, а если прошивка его режет, «ACL-толчок» через RFCOMM, после которого Android сам поднимает A2DP. Блокировка hidden API запоминается.
3. **«Рядом, но подключены к другому»** с кнопкой «Подключить к этому телефону».
4. **История заряда и прогноз** «осталось ≈ 2 ч 15 мин», скорость разряда, журнал событий.
5. **Радар поиска** по силе сигнала с вибрацией.
6. **Оповещения**: низкий заряд по компонентам, «заряжено до N %» с выбором наушники / кейс / всё, один раз за сессию зарядки.
7. **Чип Android 16 Live Updates** (если прошивка и разрешение позволяют).
8. **Другие AirPods рядом**: карточка чужих маяков, чтобы видеть, за какой зацепился Podlink.
9. **Переименование в системном списке Bluetooth** через скрытый `setAlias`.
10. **API автоматизации** для MacroDroid / Tasker: события `dev.podlink.event.*`, команды `dev.podlink.action.SET_ANC / CONNECT / REFRESH / SHOW_POPUP`.
11. **Надёжность под XOS**: сторожевой таймер раз в 15 минут, перезапуск по Bluetooth-событиям, ссылки в Phone Master / Battery Lab, уведомление «нажми, чтобы запустить», если Android запретил автозапуск.
12. **Устройство-компаньон (Companion Device Manager).** Один системный диалог, после которого Android сам разрешает фон, запуск foreground-сервиса из фона и будит Podlink, когда AirPods появляются рядом. Это официальный механизм, он не зависит от белых списков батареи XOS.
13. **Ярлыки приложения** (долгое нажатие на иконку): Подключить, Найти, Попап. Вторая плитка в шторке «Подключить AirPods».
14. **Голосовые объявления** через наушники: заряд при подключении, низкий заряд, полная зарядка (по умолчанию выключено).
15. **Экспорт истории в CSV** и кнопка «Поделиться диагностикой» в Лаборатории.

**AAP (ANC, точный заряд).** На XOS 16 Bluetooth-стек не пускает приложения к L2CAP PSM 0x1001, все варианты подключения отваливаются по таймауту. Без root на этой прошивке не работает; код и лог оставлены в «Лаборатории».

## Установка на Infinix Note 60 Ultra (XOS 16)

1. Установить `Podlink-0.5.0-release.apk`.
2. Пройти три шага: Bluetooth + уведомления, «поверх других приложений», батарея без ограничений.
3. Phone Master → автозапуск: включить Podlink. Battery Lab → Power Marathon → выключить «Screen off push block».
4. В онбординге нажать «Привязать как устройство-компаньон» и подтвердить AirPods в системном диалоге.
5. Настройки → Приложения → Podlink → Батарея → «Разрешить фоновую активность».
6. Для чипа Android 16: Настройки → Уведомления → Podlink → Live Updates.
7. Открыть кейс рядом с телефоном.

Сначала спарить AirPods обычным способом через настройки Bluetooth. Podlink работает с уже спаренными.

## Как устроено

- `ble/ProximityPacket.kt` — разбор Apple Proximity Pairing, раскладка битов сверена с OpenPods, CAPod, librepods и диссектором furiousMAC (флип, зарядка, in-ear с XOR по биту «наушник в кейсе», крышка только из кадров изнутри кейса, состояние соединения).
- `ble/PodsScanner.kt` — фильтрованный BLE-скан, захват маяка с гистерезисом и «отпечатком» (модель + цвет + пара батарей), чтобы не терять свои наушники при смене случайного адреса; лимит перезапусков скана; авто-фолбэк на программную фильтрацию.
- `bt/ClassicMonitor.kt` / `bt/ConnectHelper.kt` — слежение за A2DP/HFP, автоподключение, системный alias.
- `service/PodsService.kt` — foreground-сервис типа connectedDevice, вся логика. `service/Watchdog.kt`, `service/BootReceiver.kt` — выживание под XOS. `service/StatusIcon.kt` — иконка с процентами. `service/Notifications.kt` — каналы «подключены» / «ожидание» / «тихое ожидание», троттлинг постов.
- `ui/` — Compose: главная (hero-карточка с анимированной графикой, пилюли заряда, чипы состояния, быстрые действия), попап, история, лаборатория, настройки, онбординг.

Сборка: `cd Podlink && JAVA_HOME=<jdk17> ./gradlew assembleRelease`. Ключ подписи `Podlink/keystore/podlink.jks` (пароль `podlink`).

Если хочется реальные фото наушников: положить PNG в `Podlink/app/src/main/res/drawable-nodpi/` с именем `pods_airpods_pro.png` (или `pods_airpods_classic`, `pods_airpods_3`, `pods_airpods_max`, `pods_beats_buds`, `pods_beats_over`, `pods_beats_neck`), приложение подхватит их вместо векторной картинки.
